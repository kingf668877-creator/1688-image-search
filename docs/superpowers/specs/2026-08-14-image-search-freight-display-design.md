# 图搜结果运费按需展示设计

## 目标

图搜完成后，商品卡片只展示图搜结果本身已经返回的运费信息。不新增运费查询请求，不要求收货地址，也不展示空运费行。

## 数据规则

- 前端直接读取每个商品结果中的运费、包邮、配送、物流等已返回字段。
- 兼容常用字段名，例如 `freight`、`shipping`、`postage`、`deliveryFee`、`logisticsFee` 与包邮布尔字段。
- 字段值必须是有效运费文案、明确的金额、包邮/免邮标记，才可展示。
- 字段缺失、为空、`false`、`0` 或无可读文案时，不渲染运费区域。

## 前端呈现

- 在商品价格和店铺信息之间插入一行橙色小字：`运费：<接口原样文案>`。
- 同一套规则用于结果列表和“查看更多”弹窗的商品卡片。
- 保留图搜结果其他展示与点击跳转行为。

## 明确不做

- 不调用额外的运费接口。
- 不显示“查询运费”按钮、加载状态、失败提示或收货地选择。
- 不对接口未返回的运费进行推测、计算或补齐。

## 验收标准

1. 接口返回包邮、运费金额或配送文案的商品卡片能展示对应原始文案。
2. 接口未返回有效运费信息的商品卡片不出现“运费”标签或空白间距。
3. 页面不会新增任何独立运费网络请求。
4. 线上静态页面更新后，强制刷新可加载新脚本。
